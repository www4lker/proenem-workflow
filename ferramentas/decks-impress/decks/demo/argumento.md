# Argumento — deck de exemplo

Blocos (nós) e relações. Aprovado pelo usuário antes de qualquer coordenada.

## Nós
- `titulo` — abertura
- `problema` — por que o espaço importa
- `conceito-a`, `conceito-b` — dois conceitos que se opõem
- `figura` — síntese visual
- `midia` — vídeo de apoio
- `fechamento`

## Relações
- `problema` → deriva → `conceito-a`, `conceito-b`
- `conceito-a` ⟷ opõe-se ⟷ `conceito-b` (eixo vertical)
- `figura` sintetiza `conceito-a` + `conceito-b`

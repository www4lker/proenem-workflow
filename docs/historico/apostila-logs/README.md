# logs/

- `compilacao/` — logs de compilação LaTeX (`.log` do latexmk/pdflatex) salvos manualmente quando um erro precisa ser depurado com calma ou compartilhado com outra pessoa. Não é o destino automático dos artefatos de build normais (esses ficam e são limpos dentro de `proenem-reuniao/LaTeX-apostila/latex/`, com `latexmk -c`).
- `registro-editorial.md` — histórico cronológico manual do andamento do projeto: decisões tomadas, pendências resolvidas, reorganizações estruturais. Não repete o que já está em `docs/handoff-apostila-proenem-geografia.xml` (que é um retrato fixo do estado em 15/08/2026); é um log vivo, adicionado ao longo do tempo.

# Página de apresentação

`index.html` é a página de apresentação do repositório, enviada ao grupo Colaboradores do Enem em outubro de 2026.
É um arquivo único, sem dependências além das fontes do Google Fonts.

Para publicar no Netlify, arraste esta pasta para o painel (Sites → Deploy manually). No GitHub Pages, o modo
"Deploy from a branch" só serve a raiz ou `docs/`: copie `index.html` para um desses lugares ou use um branch próprio.

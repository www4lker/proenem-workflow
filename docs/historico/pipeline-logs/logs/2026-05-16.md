## §8.2 / §8.2b — Calibração do Pass 2

- `SKILL.md` linhas 22-24: nota de auth reescrita p/ "API key (`.env`)".
- Amostra estratificada de 10 questões (2 por faixa de ano, `random_state=42`).
- Criado **`prompts/classificar_questao.txt`** (1957 bytes) — prompt de
  classificação CH; saída JSON com `id, disciplina_principal,
  disciplinas_secundarias, tema_principal, tema_secundario, tipo_cognitivo,
  competencia, habilidade, ancoragem`. Inclui as 4 definições de `ancoragem`
  (evento_narrativo / artefato_visual / texto_analitico / composto) e a matriz
  de 6 competências CH.

**Conflito de assinatura do `ask_batch.py`** — o handoff supunha flags
`--prompt`/`--id-col` inexistentes. Assinatura real:
`--input --template --output --field-out --id-field --model --timeout`.
`--template` é string inline interpolada via `str.format(**row)`. Passar o
arquivo de prompt direto quebraria (ele contém `{}` literais do schema JSON).
**Padrão adotado (vale para todo o Pass 2):** pré-montar um CSV com a coluna
`prompt_completo` (prompt + JSON da questão) e rodar
`ask_batch.py --template "{prompt_completo}"` — substituição única, não
reinterpreta as chaves do valor. Reusa o checkpoint do `ask_batch.py`.

**Calibração** — 10/10 chamadas `ok`, mas só 4/10 parseavam: o Gemini embrulha
o JSON em fence ` ```json `. Criado **`scripts/strip_and_parse.py`** que remove o
fence e faz `json.loads` → grava `id, classificacao, parse_ok[, erro]`. Pós-fix:
10/10 parseiam. `2025_CH_040` parseou mas com tema "Cannot classify…": causa =
`enunciado` NaN na fonte (ver dívidas).
